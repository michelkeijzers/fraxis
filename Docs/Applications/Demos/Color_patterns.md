# COLOR PATTERNS (MANUAL)

## DESCRIPTION

Color Patterns is a dynamic visual demo and hardware visualization utility designed for low-resolution matrix displays ($5 \times 72$ horizontal playfield or $16 \times 16$ square matrix). It generates animated algorithmic lighting effects, color shifts, and geometric patterns. Users can manipulate animation presets, color palettes, speeds, and rendering modes in real time using dual joystick controls, with active configuration status displayed on the secondary LCD2004 screen.

## ALTERNATIVE NAMES

* LED Kaleidoscope

Both ($5 \times 72$ or $16 \times 16$)

## HARDWARE INTERFACE

### Displays

* **Main LED Matrix (**$5 \times 72$ **or** $16 \times 16$**):** Displays the active rendered visual color pattern and animation effects.
* **LCD2004 (20x4 Character Display):** Displays current pattern names, active color palettes, animation speed, brightness levels, and parameter values.

### Dual Joystick Controls

| Control Input | Function | Description | 
| ----- | ----- | ----- | 
| **Joystick 1 (Up / Down)** | Select Pattern | Cycles through available pattern algorithms. | 
| **Joystick 1 (Left / Right)** | Select Color Palette | Cycles through active color schemes. | 
| **Joystick 1 Button** | Toggle Mode / Pause | Pauses animation flow or toggles specific visual sub-modes. | 
| **Joystick 2 (Up / Down)** | Speed Control | Increases or decreases the animation refresh rate. | 
| **Joystick 2 (Left / Right)** | Parameter Adjust | Modifies pattern density, scale, or direction parameters. | 
| **Joystick 2 Button** | Randomize / Reset | Instantly randomizes active parameters or resets settings to defaults. | 

## CORE FEATURES

### Real-Time Pattern Rendering

Color Patterns continuously computes dynamic visual algorithms rendered directly to the main WS2812B matrix:

* **Real-time Navigation:** Change patterns smoothly on the fly without stopping execution.
* **Dual-Joystick Parameter Control:** Adjust speed and pattern density simultaneously using separate analog/digital inputs.
* **Instant Visual Feedback:** Live updates on matrix animations as settings are modified via joysticks.

### LCD2004 Status & Menu Display

The secondary LCD2004 screen acts as a live parameter readout during operation:

```
+--------------------+
| PATTERN: Rainbow Wave|
| PALETTE: Neon RGB  |
| SPEED: 85% DENS: 4 |
| [J2-Btn: Randomize]|
+--------------------+
```

* **Line 1:** Currently selected pattern algorithm.
* **Line 2:** Active color palette scheme.
* **Line 3:** Real-time speed percentage and pattern spatial density level.
* **Line 4:** Contextual button hints and action feedback.

## PATTERN ALGORITHMS

### Rainbow Wave
**Description:** A smooth, rolling spectrum gradient that shifts across the matrix length or outward from the center. Uses trigonometric functions ($sin/cos$) to create seamless rainbow color transitions.

### Plasma Flow
**Description:** A fluid visual effect generated by overlapping multidimensional sine waves. Produces swirling, organic liquid-like pools of shifting color.

### Concentric Ripples
**Description:** Simulates water drops falling onto a surface. Expands circular or linear wave rings outward from random or fixed focal points across the grid.

### Fire Simulation
**Description:** A thermal convection simulation. Heat points spark at the base of the matrix and rise upward, cooling into deep reds, glowing oranges, and hot yellows.

### Matrix Digital Rain
**Description:** Inspired by classic terminal code cascades. Glowing bright green (or palette-mapped) "heads" trail fading green tails downward across matrix columns.

### Snake Race
**Description:** Autonomous multi-pixel "snakes" weave across the matrix grid simultaneously, changing direction upon encountering edges or each other while leaving temporary fading light trails.

### Galaxy
**Description:** A deep space visual simulation featuring twinkling white and cool blue/cyan star pixels rotating around a dense cosmic core or drifting slowly across the void.

### Knight Rider (Cylon Scanner)
**Description:** A high-contrast oscillating laser beam sweeping continuously back and forth across the horizontal or vertical axis, featuring an incandescent trailing fade effect.

### Stroboscope
**Description:** High-frequency, synchronized full-matrix flashes at controllable pulse intervals. Designed for intense hardware testing or rhythm visualizer effects.

### Starfield (Warp Drive)
**Description:** Displays central point expansion where pixel stars accelerate toward the outer edges of the matrix, creating the visual effect of moving forward through space at warp speeds.

### Bouncing Balls
**Description:** Simulates several elastic physics-based energy spheres bouncing off the grid borders, exchanging momentum and producing dynamic color flashes upon wall contact.

## ADDITIONAL SETTINGS DETAILS

### Animation Speed

Sets the refresh step frequency for pattern movement.

Values:
* 10% (Slow motion) to 200% (High speed)

Adjustable directly using **Joystick 2 (Up / Down)**.

### Pattern Density

Controls spatial scaling and wave frequency across the matrix grid.

Values:

* Low (Wide, broad gradients)
* Medium (Standard scale)
* High (Tight, detailed patterns)
* Ultra (High-frequency noise or sharp waves)

Adjustable directly using **Joystick 2 (Left / Right)**.

### Auto-Cycle

Enables autonomous demo operation without requiring joystick interaction.

Values:

* Off
* 5 - 60 seconds interval

When enabled, the demo periodically cycles to the next pattern type while maintaining user-defined brightness and speed limits.

This project's personal goal is to learn more about ESP32 with ESP-IDF programming.

The project is a retro style computer with instead of a screen a 5x72 LED matrix, two joysticks (for each player), an 20x4 display, a display for time and scoring per player and a button and some LEDs.
At a later stage also sound will be incorporated (passive buzzer, I2s microphone and speaker, mono).

The idea is to be able to show demos, games and tools.
